# 1.19.4：修正评审渠道，失败时不跳过检查

1. **Skill 名字不再当成模型选择**：说“使用 Codex with ChatGPT”默认仍走 DeepSeek；明确说用 GPT 才切换。命令会核对原始要求与指定渠道，不能拿自拟摘要替换你的要求。
2. **常见说法也能识别**：“网页版 ChatGPT”、带链接的模型名和“交给 ChatGPT 评审”都支持；明确说不用某渠道时，不会反过来选中它。
3. **评审失败不能当作通过**：没有发送成功、没有有效回复或门槛未通过，就不改业务文件和系统配置。取消时先停止本地执行，远端取消失败也不会被旧记录重新放行。
4. **截图不会擅自换渠道**：默认由 Codex 看图、整理成文字后交给 DeepSeek；只有选择 ChatGPT 且工具可用时，才走对应的只读图片工具。
5. **授权故障说明更清楚**：浏览器控制拿不到授权不等于网站没登录或额度用完。普通业务任务不会自行重配全局认证、关闭 Codex 或换浏览器。

本次验证区分本地自动化、实际浏览器控制和完整方案评审；不把旧版三轮耗时当作本版新复测。详情见 [检查记录](https://github.com/ssqaq/codex-with-chatgpt-skill/blob/master/docs/verification/1.19.4.md)。
