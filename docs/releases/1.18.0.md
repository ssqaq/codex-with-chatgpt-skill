# 1.18.0：把多轮评审容易卡住的地方补齐

默认还是让 DeepSeek 想方案，让 Codex 改文件。说“用 GPT/ChatGPT”时才切换渠道。

1. 安装包补齐：配套文件一起安装，缺文件或版本不一致会报出来，更新前保留备份。
2. 不再过早停下：DeepSeek 正常思考时继续等待，不会看两次没变化就暂停。
3. 发送前检查当前网页：输入框不能用、原会话不对、消息已存在时先核对，不盲目重复发送。
4. 等待时间更清楚：任务运行时，每满一分钟显示当前轮次、已等待多久、最近什么时候检查过网页。重启恢复后接着计时。
5. 中断后找回进度：保存轮次和短摘要；恢复后先核对原网页，不能直接恢复修改权限，也不会接到其他任务。
6. 增加故障复测：覆盖全新安装、缺文件、页面失效、等待较慢、重复发送、重启和记录损坏。自动发布等待测试通过。
